# Changelog

## 2.0-gecko

- substituído Android WebView por Mozilla GeckoView;
- URL padrão alterada para `?ambiente=recepcao&tv=1`;
- sessão persistente e isolada para a Recepção;
- WebExtension interna para abrir “Acesso restrito” automaticamente quando necessário;
- navegação espacial para controle remoto;
- foco visual dourado nos elementos selecionados;
- tela offline nativa e repetição automática;
- menu oculto alterado para segurar VOLTAR por 3 segundos;
- limpeza completa de cookies, storage e autenticação pelo menu;
- tela mantida ligada e modo imersivo.
